# Battery Orchestrator

Carga y descarga adaptativa de baterías domésticas por precio de la luz,
producción solar y consumo real de la casa. Sin programación lineal ni
parámetros ocultos: un algoritmo de dos pasadas que puedes leer de arriba
a abajo, con interfaz web para declarar tus baterías, tarifa y paneles
solares.

Ver [DOCS.md](DOCS.md) para instrucciones de configuración.
